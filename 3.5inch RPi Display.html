Driver Installation

This LCD Module need install driver first.
First download the Raspberry Pi system
We currently recommend the May 13th version of the Raspberry Pi system. downloads.raspberrypi.org​
Burn the system image
If you don't know how to do that,you can refer to the Raspberry Pi office tutorial
Connect to the Raspberry Pi using ssh and execute the following commands (make sure your network has access to github or apt repositories, otherwise some of the dependencies will fail to install)
sudo rm -rf LCD-show git clone https://github.com/goodtft/LCD-show.git chmod -R 755 LCD-show cd LCD-show/ sudo ./LCD35-show
Above are the RaspberryPiOS related installation commands
ALT
​
After the execution is complete the Raspberry Pi will reboot, wait a few minutes and you will see the screen display.

Touch screen calibration

(This step is not mandatory and should only be performed if the touch is incorrect.)
This LCD can be calibrated using a program called xinput_calibrator
We have placed the program in the driver directory,Install it with the commands:
cd LCD-show/ sudo dpkg -i -B xinput-calibrator_0.7.5+git20140201-1+b2_arm64.deb
​
Click the Men button on the task bar, choose Preference -> Calibrate Touchscreen.
Finish the touch calibration following the prompts. Maybe rebooting is required to make calibration active.

How to rotate the display direction

To rotate the display direction, you need to install the driver first, you can refer to this section to install the driver.Driver Installation
If the driver installation is complete, you can execute the following command to select the screen orientation
cd LCD-show/ sudo ./rotate.sh 90
​
After execution, the system will automatically restart, and the display screen will rotate 90 degrees to display and touch normally.
' 90 ' can be changed to 0, 90, 180 and 270, respectively representing rotation angles of 0 degrees, 90 degrees, 180 degrees, 270 degrees

Kali Linux & Ubuntu MATE Tutorials

It is recommended to directly download and burn the configured image at the bottom of the page

Kali Touch Calibration

cd LCD-Show-kali (Pi4 and Pi5 need to execute the following command, but not if you are a Pi3 version) sudo sed -i -e '$a\' /var/lib/dpkg/info/*.list sudo dpkg -i -B xinput-calibrator_0.7.5+git20140201-1+b3_arm64.deb
​
After execution, click the Kali icon button on the top left corner of the desktop, enter Calibrate Touchscreen, and click the icon to enter the calibration process.
Follow the prompts to complete the calibration, you may need to reboot to activate the calibration.

Kali Angle adjustment

cd LCD-Show-kali sudo ./rotate.sh 90
​
After execution, the system restarts automatically and the display rotates 90 degrees for normal display and touch.
(You can change 90 to 0 90 180 270, which represents the rotation angle of 0, 90, 180 and 270 degrees respectively)

Ubuntu MATE Touch Calibration

cd LCD-show-ubuntu sudo dpkg -i -B xinput-calibrator_0.7.5-1_armhf.deb
​
After execution, click the icon button on the top left corner of the desktop, enter Calibrate Touchscreen, and click the icon to enter the calibration process.
Follow the prompts to finish calibration, you may need to reboot to activate the calibration.

Note: Ubuntu MATE cannot be angled.
